# HortiVita

Website institucional da HortiVita, um sistema hidropônico compacto e giratório para cultivo em pequenos espaços.

## Site

Depois da primeira publicação pelo GitHub Actions, o endereço será:

https://benatojhony.github.io/HortiVita/

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

O conteúdo está organizado em páginas separadas para início, história, funcionamento, soluções, projetos, recursos e contato.
